# 大偏移单相支撑

用户要求大偏移中间错开三个绝缘子，每个绝缘子配一个独立支架，并参考原项目。

只读核对原项目的 `CreateFaceToFaceLargeOffsetMember`、`FaceToFaceFramePreviewPosePlanner` 和 `FaceToFaceFrameInsulatorDriver`：原安装关系按每个物理连接基架分别管理三相组，正负偏移用相应安装轴，中间段分节后也按物理架归属安装。本项目沿用这一归属和实际铜排位置，将中间连接架的普通三相共用横担改为三个单相支架。

错开量从实际三相宽度向铜排的纵向中心差取得，横向位置按各相直排取得，本体高度按最下层铜排承托面与基架底部安装基准计算。三相共用的纵向平移优先取零，必要时只在原直段和原搭接避让允许的区间内调整；不缩小相位错开量，也不改铜排、基架或绝缘距离。缺相、叠排数量/间距不符、安装高度或长度不足时明确拒绝。

每个支架只启用对应相的一个本体，另外两个模板兼容位保持压缩。三个支架分别保留稳定安装身份，参数导出、孔位映射、模型显示和实体检查共用同一逐位安装计划。恢复旧草稿时也按当前实际中间排派生大偏移支撑。

本轮静态语法、支撑类及参数导出接口的独立类型编译检查通过。没有构建解决方案、注册插件或启动 SolidWorks、计算 Worker。新增的纯数值回归在 `tools/verification/LargeOffsetSupportProbe.cs`，覆盖面对面/侧对侧、正负偏移、单节/多节、三个单相支架、重复计算、参数安装位以及缺相/空间不足拒绝；回归尚未运行。原全量验证保持暂停，恢复后需补新布局的完整实体净距、支架干涉和实机预览检查。
