# 重新规划与验证状态

参数变化后，面对面或侧对侧联动方案出现干涉或规划冲突时，提示是否按当前输入重新规划。确认后重新设计母排、基架和绝缘子，清除旧人工位置、长度、锁定及吊架方案；普通读取继续沿用当前草稿。没有已加载方案时，“重新规划”也走全新设计入口。重新规划后仍保留原净距、干涉及安装校验，失败结果不能覆盖成成功提示。

兼容几何分支将同一根铜排的构造分段合并为一个物理检查对象，并保留局部网格和双精度安装平移；不同根铜排的真实重叠和非相邻路径自交仍检查。偏移立弯已使用独立的连续圆弧入口，不再用方柱分段显示。

测试工具包括 `--replan-flow`、`--replan-offset <报告路径>` 和 `--reference-cases <本机输入路径> <报告路径>`。参考输入由 `tools/Import-ReferenceTestParameters.py` 只读导入，模型参数、回归矩阵和历史场景共 105 条，历史运行数据去重后另补 16 条。导入参数及完整报告留在本机，不进入公开仓库；仓库仅提供测试代码和导入工具。

2026-11-18 已完成 71/121 条旧包验证：51 条通过、17 条被校验阻止、2 条计算拒绝、1 条源参数不完整。队列按用户安排暂停，剩余 50 条尚未完成，断点与完整报告保存在本机。批量工具退出码只表示是否处理完输入记录，各条是否通过必须读取报告中的结果和校验字段。

暂停前完成过重新规划交互、偏心距 0→50 mm 和几何检查的离线核对；侧对侧仍有低于 125 mm 的真实净距问题，不能报告整体通过。暂停后修改了立弯网格和大偏移支撑，这些新几何目前仅完成静态检查及部分纯托管类型编译，新增回归未运行。恢复验证后必须用新版本重新记录结果；旧包 71 条结果不能作为新布局的通过依据。没有进行本轮 SolidWorks 实机验证。
