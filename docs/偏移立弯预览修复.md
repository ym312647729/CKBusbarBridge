# 偏移立弯预览修复

用户确认面对面、侧对侧偏移的立弯都有问题。旧转换按路径逐段生成方柱，再拼接或合并，缺少圆弧和连续的截面方向；相邻直段独立投影排宽，不能代表原版立弯。

本轮只读对照原版 `VerticalBendPreviewAdapter`、`VerticalBendSetting.GetWidthVector / Segmentation`、`VerticalBendPreviewBody` 以及 `OffsetLineSegment`。起始排宽取路径方向与原排厚方向的叉乘；适配器的半厚侧面定位由原版单侧拉伸抵消，源路径按截面中心解释。新预览复用已有的矩形截面扫掠，沿各段传递截面，分别用排厚和平弯半径、排宽和立弯半径确定圆弧与切线占长。不改路径、柜端定位、原折弯补偿值和相序；铣排沿用原独立分支。

完整实体先在零件局部计算，显示与物理检查共用同一网格和双精度安装变换。圆弧切入、切出边线留在网格所属局部坐标系；孔位投影使用扣除切线占长的直段。过大的半径、隐式截面扭转、自交和不连续实体仍会拒绝，不缩小半径或放宽净距门禁。

新增 `tools/Test-OffsetVerticalCopper.mjs`，涵盖面对面及旋转后的侧对侧 50 mm 偏移、45°圆弧的独立解析体积、连续实体、90°立弯、平立混合、真实开孔、安装定位及大坐标局部网格。此前的混合铜排回归已删除“与方柱外形相同”的过时断言，保留不同根重叠、自交及孔后网格检查。

当前全量验证按用户安排保持暂停。本轮仅进行语法、差异和运行清单静态核查；上述纯几何回归尚未执行，未构建项目或运行 SolidWorks。恢复验证后应以新几何单独记录结果，不能把此前 71 条的旧网格结果作为本次修复的验证依据。
