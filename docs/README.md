# 中压母线桥项目试用版

项目名：`CKBusbarBridge`。参数窗口使用 RD.UI.Wpf，贴靠屏幕工作区右侧，底部为任务进度留出空间。柜体和母线桥在同一窗口内设计：左侧约三分之一为柜体参数，右侧为母线桥设计；中间可拖动调整，柜体区可以折叠并通过顶部中文标签展开。参数窗口不显示图片和二维预览；SolidWorks 视口负责模型预览。生成按钮仅提示“实体生成暂未开发”。

- 从「柜体设计」或「母线桥设计」进入时，先创建并激活空总装，再打开同一个整体参数窗口并自动规划完整预览。同一个窗口有「面对面」「面对墙」「侧对侧」三个页签；面对墙可在页内选柜前或柜后向墙。切换时复用同一空总装；切回某页可继续本次输入。已有本项目草稿可直接继续编辑。柜体、基座、铜排、基架、绝缘子及吊架只在视口显示，退出时可保存参数和空总装。不开放正式桥体生成、实体开孔、已生成模型的二次驱动或 BOM 命令。
- 保留开孔库设置、关于、出工程图和铜排出图。出图仅针对用户已打开的实物装配体；柜体工程图要求项目已有相应工程图文件。随项目仅保留本项目图纸模板。
- 保留驱动视口显示所需的离线几何定义和算法 Worker。离线定义不是可在 SolidWorks 中打开的模型。
- 源码及运行目录与原插件独立，试用版只恢复自己的草稿。

开孔库、铜排出图、图号及关于窗口同样使用 RD.UI.Wpf。普通提示和进度显示在右下角；需要用户选择的确认框使用 RD.UI.Wpf 对话框。铜排出图窗口调用隔离运行域内原 DLL 的无界面出图接口。

母线桥设计沿用中压母线桥的对象列表列头，以及下方「参数 / 推荐值 / 当前值 / 提示与操作」属性区。宽度不足时将两张对象列表上下排列。编辑已在视口中标注的尺寸时，数字外围显示红框；切换输入框或离开输入框时更新或清除红框。

首次进入各柜体页时，自动使用该场景的默认参数：面对面柜间距 3500 mm，面对墙柜到墙距离 1340 mm（柜前、柜后向墙相同），侧对侧柜间距 1000 mm。各页保留本次输入。

视口根据柜体与柜体或墙的实际定位面标注间距，柜体、间距、偏心、基座等尺寸用不同颜色区分。选中输入框时，对应数字加红框。双击柜体或母线桥视口尺寸时，打开靠近点击位置的数值框并选中原值；点击视口空白处提交，右键或 Esc 取消。输入过程不触发试改或更新模型。

## 增量编译

需要 .NET Framework 4.8 开发包、支持 WPF 的 VS MSBuild、.NET SDK 及 Node.js 22 或以上。首次拉取用 VS MSBuild 执行以下命令，编译不会注册 COM：

```powershell
msbuild CKBusbarBridge.sln /restore /t:Build /p:RestorePackagesConfig=true /p:Configuration=Debug /p:Platform="Any CPU" /p:RegisterForComInterop=false /p:SkipSolidWorksRegistration=true
```

本地包源在 `.nuget/local-feed`。面对墙等方案所需的默认算法授权随母线桥试用版提供，无需安装联络排。需要单独配置时，在运行 SolidWorks 的 Windows 账号下执行 `pwsh -File tools/Set-WorkerAuthorization.ps1`，本机加密授权优先于内置授权；进程环境变量 `CK_BUSBAR_WORKER_AUTHORIZATION` 优先级最高，可用于临时覆盖。预览源码或运行资源修改后执行 `pwsh -File tools/Update-ParameterPreviewManifest.ps1`。不把原项目客户模型、模板压缩包、试验记录或用户设置复制到该仓库。

## 独立计算与基座规则

- 计算源码在本仓库的 Worker 目录。CKBusbarBridge.Computation.dll 不引用 SolidWorks、WPF 或插件程序集；它接收参数快照，调度常驻计算进程，返回网格、安装位置和尺寸。面对墙接口识别也在这个 DLL 内完成。
- Debug 自动构建本项目的母线桥专用路径 Worker。输出统一放在插件的 bin/Debug/Worker，内含计算 DLL、Algorithm、PreviewRuntime 和 Runtime 子目录；Node 引擎从开发机已安装版本复制到 Runtime。运行时不依赖其他项目的安装目录，不携带方案库、数据库或客户模型。
- 固定模板依旧由代码生成。缓存只复用相同输入生成的网格和已完成的检查；几何、安装位置、相序或绝缘要求变化时重新检查。旋转视角不重新计算几何。
- 独立计算按逻辑核心数减 3 限制并发，最少一路；几何生成与实体检查共用有界工作池。当前开发机三轮对比中，完整预览中位耗时由 4351 ms 降至 2204 ms，结果逐项一致，详见[速度验证](独立计算速度验证.md)。
- 面对面和面对墙的普通基座：宽度取所属柜体宽度，深度取柜顶深度定位尺寸加 41.5 mm。侧对侧保留原 Base1、Base2 的不同尺寸映射与增高关系。
- 柜体与基座底部安装孔不再显示，安装孔 L1、L2 输入移除；保留柜顶矩形通口、其半宽 L3，以及基座尺寸和定位参数。旧输入数据中的兼容字段不作为可编辑孔位公开。
- 面对墙钢架的安装孔、腰孔及其阵列同样不显示；安装基准、铜排通口及钢架外形保持。原孔草图只作为折弯材料侧与安装位置的几何见证，不再生成孔壁。
- 面对墙先显示柜体、基座和支架等固定组件，再启动中间铜排求解。第一个发布候选通过原有完整安装、制造和绝缘校验后立即预览，后台继续按 60000 ms 总时限搜索。修改参数、切换场景或关闭窗口会取消旧任务，旧修订不得覆盖当前预览。

面对墙基座与柜顶通口沿用原适配器的 `BaseToCabinetEdgeDistance`，固定伸出排单独使用 `BusbarCenterToCabinetEdgeDistance`。两者独立定位；修改铜排中心不会带动基座。预览相序按实际绝缘子逻辑端位统一，安装板保留套管贯通口，套管嵌件与绝缘本体分别占据实体空间，角钢端部按安装位置修配。完整实体检查包含钢架和套管安装板，仍使用 125 mm 默认净距及原干涉阈值。

独立速度验证工程为 Worker/CKBusbarBridge.Computation.Bench；它无需启动 SolidWorks。常规场景同时核对 343 个部件、零干涉和 125 mm 最小对地净距，并验证绝缘设置变化会触发重新检查。合并界面的离线检查源码在 tools/verification/UnifiedDesignProbe.cs。测试器附加 --stream-wall 命令可验证实际路径 Worker 的首次发布与一分钟持续搜索，不操作 SolidWorks。

## Visual Studio 调试

1. 在 VS 打开 `CKBusbarBridge.sln`，将 `CKBusbarBridge` 设为启动项目，生成 `Debug | Any CPU`。插件实际编译为 x64，输出位于 `CKBusbarBridge/bin/Debug`。
2. 保存工作并退出已运行的 SolidWorks。用同一个 Windows 帐号以管理员身份运行 [Register-Debug.bat](../tools/registration/Register-Debug.bat)。脚本先卸载此插件的旧 COM 注册，再注册固定 Debug 目录中的 64 位插件。加载项和命令页显示为「中压母线桥」，默认随 SolidWorks 启动加载。
3. 在项目属性的「调试」页选择「启动外部程序」，指向本机的 `SLDWORKS.exe`，再按 F5。配置保存在自己的 `.csproj.user` 中。例如本机 SW 2024 为 `D:\sw2024\SOLIDWORKS\SLDWORKS.exe`。

之后在同一目录编译时不必重新注册。结束当前 SolidWorks 调试会话，修改代码后按 F5 即可。仅在换工作副本、改输出目录或其他版本覆盖了注册时重跑脚本。断点未绑定时，在 VS「调试 → 窗口 → 模块」核对 `CKBusbarBridge.dll` 的加载路径与符号状态。

SolidWorks 的面对面常规预览中，基架骨架在顶板、侧板和底板内侧。外壳两端根据已安装基座的顶面和左右侧面定位；两端宽度不同时外壳平滑衔接，不改铜排或支撑坐标。基座与基架侧板按中压预览的冲压百叶样式生成向下的开口。A、B 柜的基座总高分别沿用各自参数，包含顶盖。若两端接口不再等高，视口仍显示当前柜体与基座，并暂停显示旧桥体，直到参数允许重新规划。增量编译后可运行 `node tools/Test-FacingRegularPreview.mjs --solidworks-preview` 离线核查 SolidWorks 预览几何，无需启动 SolidWorks 或浏览器。

换相、小偏移、大偏移、侧对侧和面对墙也使用同一套实体板件。小偏移与面对墙宽高过渡保留端部封板和有效通口；大偏移拐角保留两个相邻通口；侧装换相架根据模板姿态转换顶、底和侧板。侧对侧基座使用铜排规划已确认的同一套安装坐标，增高基座保留贯通。运行 `node tools/Test-StructurePreviewVariants.mjs` 可离线核对各模板外壳、通口及板件干涉。桥体的绝缘净距和干涉不足会显示在设计窗口；保留原母线规划和净距标准。

## 面对面常规虚拟测试

Debug 增量编译解决方案后，启动 `CKBusbarBridge.WebTest/bin/Debug/net48/CKBusbarBridge.WebTest.exe`。程序只监听本机回环地址并打开默认浏览器；关闭控制台即退出。参数页复用柜体业务字段，三维视图支持中键旋转、Ctrl + 中键平移、滚轮缩放、视图切换和双击尺寸修改。模型页可分组或逐件隐藏、隔离显示及恢复全部。屋面和地面等环境参照默认隐藏；基座和基架的平盖板默认显示，可在「模型 → 盖板」独立开关。

柜体、柜顶基座、基架、支架、吊架和绝缘子由方案 B 的代码生成。面对面常规的原安装坐标、参数和母线几何仍由现有规划链提供。柜顶板按柜体名义高度落位，并根据伸出排截面和设置的绝缘净距生成让位口；柜顶基座的板件止于与基架的安装面。绝缘净距出厂值为 125 mm；可在插件「项目设置」或测试网页「设置」中修改默认值，已有草稿保留自己的参数。

测试器使用同一规划与网格链，并用试验圆孔替代工艺库输入。报告分别显示装配干涉数量、相间最小净距和母线对金属的最小净距。装配干涉使用各零件实际网格求实体交集，排除接触面和小于或等于 0.001 mm 的数值薄片；隐藏模型只影响画面。Debug 增量编译后可用 Node.js 22 或以上运行 `node tools/Test-FacingRegularPreview.mjs`，回归默认参数和柜宽、柜间距调整后的面对面常规场景。

WebGL 直接使用共用网格生成的闭合三角面，SolidWorks OpenGL 使用同源的四边面和局部三角面。两者共用真实棱边、孔口及折弯切入切出线；三角面内部对角线和圆弧采样缝不参与边线显示。网页使用相序颜色和 15% 铜排透明度。

测试器用于本机核对，尚未用于出厂或施工验收。部分原几何定义仍作为老场景和接口兼容数据，包含此类定义的测试目录不用于对外分发。
